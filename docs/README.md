# Документация проекта geometric_lib

## Общее описание
Проект geometric_lib - это python математическая библиотека с функциями для вычисления площадей и периметров геометрических фигур.
- `circle.py` - круг;
- `square.py` - квадрат;
- `rectangle.py` - прямоугольник;
- `triangle.py` - треугольник.

В каждом модуле находится две функции:
- `area(x)` - функция для подсчета площади геометрической фигуры;
- `perimetr(x)` - функция для подсчета периметра геометрической фигуры;
## Функции
- Каждая функция снабжена блоками коментарий с описанием самой функции, принимаемых аргументов, выводимого значения
- Также к каждой функции в блоке коментарий и в этом файле прилагается пример использования

### circle.py

- `area(r)` — принимает радиус `r`, возвращает площадь круга.
  Пример: `area(2)` -> `12.566370614359172`
```
    Принимает число r, возвращает площадь окружности с радиусом r

    Параметры:
        r (float) : задаваемый радиус

    Возвращаемое значение:
        area (float) : число Пи умноженное на квадрат радиуса

    Пример вызова:
        area(1) -> 3,1415...
```

- `perimeter(r)` — принимает радиус `r`, возвращает длину окружности.
  Пример: `area(2)` -> `12.566370614359172`
```
    Принимает число r, возвращает периметр окружности с радиусом r

    Параметры:
        r (float) : задаваемый радиус

    Возвращаемое значение:
        area (float) : число Пи умноженное на удвоенный радиус

    Пример вызова:
        area(0.5) -> 3,1415...
```
### square.py

- `area(a)` — принимает сторону квадрата `a`, возвращает площадь квадрата.
  Пример: `area(5)` -> `25`
```
    Принимает число a, возвращает Площадь квадрата со стороной а

    Параметры:
        a (float) : задаваемая сторона квадрата

    Возвращаемое значение:
        area (float) : квадрат числа a

    Пример вызова:
        area(1) -> 1
```

- `perimeter(a)` — принимает сторону квадрата `a`, возвращает периметр квадрата.
  Пример: `area(5)` -> `20`
```
    Принимает число a, возвращает периметр квадрата со стороной а

    Параметры:
        a (float) : задаваемая сторона квадрата

    Возвращаемое значение:
        perimetr (float) : сторона квадрата умноженная на 4

    Пример вызова:
        perimetr(1) -> 4
```

### rectangle.py

- `area(a, b)` — принимает стороны прямоугольника `a` и `b`, возвращает площадь прямоугольника.
  Пример: `area(5, 5)` -> `25`
```
    Принимает числа a, b, возвращает площадь прямоугольника со сторонами a, b

    Параметры:
        a (float) : задаваемая длина
        b (float) : задаваемая ширина

    Возвращаемое значение:
        area (float) : длина умноженная на ширину

    Пример вызова:
        area(1, 1) -> 1.0
```

- `perimeter(a, b)` — принимает стороны прямоугольника `a` и `b`, возвращает периметр прямоугольника.
  Пример: `area(5, 5)` -> `20`
```
    Принимает числа a, b, возвращает периметр прямоугольника со сторонами a, b

    Параметры:
        a (float) : задаваемая длина
        b (float) : задаваемая ширина

    Возвращаемое значение:
        perimetr (float) : удвоенная сумма длины и ширины

    Пример вызова:
        perimetr(1, 1) -> 4.0
```

### triangle.py

- `area(a, h)` — принимает сторону треугольника `a` и высоту к этой стороне `h`, возвращает площадь треугольника.
  Пример: `area(2, 2)` -> `2`
```
    Принимает числа a, h, возвращает площадь треугольника со стороной а и высотой к этой стороне h

        Параметры:
            a (float) : задаваемая сторона
            h (float) : задаваемая высота

        Возвращаемое значение:
            area (float) : половина стороны умноженной на высоту

        Пример вызова:
            area(1, 1) -> 0.5
```

- `perimeter(a, b, c)` — принимает стороны треугольника `a, b, c`, возвращает периметр треугольника.
  Пример: `area(1, 1, 1)` -> `3`
```
    Принимает числа a, b, c, возвращает периметр треугольника со сторонами a, b, c

    Параметры:
        a (float) : задаваемая сторона
        b (float) : задаваемая сторона
        c (float) : задаваемая сторона

    Возвращаемое значение:
        perimetr (float) : сумма длин всех сторон

    Пример вызова:
        perimetr(1, 1, 1) -> 3.0
```
